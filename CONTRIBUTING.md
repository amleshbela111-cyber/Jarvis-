# Contributing to Jarvis

Thank you for helping. Jarvis can control a phone, so every change is reviewed carefully.

## How to contribute
1. Fork this repository.
2. Make your change in a branch of your fork.
3. Open a pull request using the template.
4. The automatic review runs. Read its report.
5. A maintainer reviews and approves. Changes are never merged or pushed without a maintainer's approval.

## Rules
- **Never** put an API key, token, password, personal email, or private key in code, comments or files.
- Keep permissions and network access to what the feature really needs. Explain any new one in the pull request.
- Do not add code that hides what it does, downloads and runs code, or sends data somewhere without the user knowing.
- Keep the user in control: anything that sends a message, spends money, deletes data or installs an app must ask first.
- Small, focused pull requests are easier to review.

## Reporting a security problem
See SECURITY.md. Do not open a public issue for a security problem.
